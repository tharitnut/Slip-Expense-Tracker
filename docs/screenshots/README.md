# Screenshots Directory 📸

Place your project screenshots here to be referenced in the main `README.md`.

### Recommended File Names & Specs:
1. `dashboard-light.png` — Monthly Dashboard in Light Mode (showing KPI cards, donut & bar charts)
2. `dashboard-dark.png` — Monthly Dashboard in Dark Mode (matching view to showcase the dark theme)
3. `upload-ocr.png` — Slip Upload page showing the dropzone and parsed receipt review card
4. `transactions.png` — Transactions page showing the minimalist table, filters, and badges

> **Tip:** Recommended resolution is around 1280x720 or 1440x900 for crisp rendering on GitHub.
